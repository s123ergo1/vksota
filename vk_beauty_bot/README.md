## ✨ Особенности

- 📋 **Главное меню** с категориями услуг в виде аккуратных кнопок.
- 🔍 **Подменю категории** с полным перечнем услуг, ценами и длительностью (с постраничной навигацией).
- 🪧 **Карточка услуги** — название, цена, время и описание.
- 📅 **Запись в один клик** — бот подтверждает выбор и передаёт заявку менеджеру.
- 💬 **Кнопка «Обратиться к менеджеру»** всегда под рукой на любом экране.
- ⬅ **Навигация «Назад»** между уровнями меню.
- 🛡 **Устойчивая обработка ошибок** — невалидный ввод возвращает пользователя в главное меню.

## 🧱 Стек и архитектура

| Компонент | Назначение |
|-----------|-----------|
| **[vkbottle](https://github.com/vkbottle/vkbottle)** | Асинхронный фреймворк для VK API (поллинг, роутинг, клавиатуры) |
| **python-dotenv** | Безопасная загрузка токена из `.env` |
| **VkKeyboard / Text / Callback** | Декларативная сборка клавиатур |

Проект разбит на модули с чёткими зонами ответственности (принцип единой ответственности):

```
vk_beauty_bot/
├── main.py         # точка входа: создание Bot, регистрация обработчиков, запуск Long Poll
├── keyboards.py    # генераторы всех клавиатур (main / category / service_detail)
├── services.py     # каталог услуг (SERVICES) — данные отделены от логики
├── handlers.py     # вся бизнес-логика: навигация, карточки, запись, менеджер
├── config.py       # загрузка переменных окружения
├── requirements.txt
└── .env.example
```

> 💡 **Архитектурное решение:** данные (`services.py`) полностью отделены от представления (`keyboards.py`) и поведения (`handlers.py`). Добавить новую услугу или категорию можно, отредактировав только один словарь.

## 🚀 Быстрый старт

### 1. Клонирование и окружение

```bash
cd vk_beauty_bot
python -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate           # Windows
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка токена

Создайте файл `.env` рядом с `main.py`:

```env
VK_TOKEN=ваш_токен_группы_вк
MANAGER_CHAT_ID=
```

Токен берётся в `Управление сообществом → Настройки → Работа с API → Ключи доступа`.

### 4. Включение Long Poll

В настройках группы (`Управление → Интеграции → Long Poll API`) добавьте событие
**«Входящие сообщения»**.

### 5. Запуск

```bash
python main.py
```

Бот начнёт слушать события. Напишите что-нибудь в личные сообщения группы — и получите главное меню. 🎉

## 🧠 Ключевые детали реализации

- **Пагинация подменю.** VK ограничивает inline-клавиатуру 6 строками и подпись кнопки — 40 символами, поэтому список услуг разбит на страницы (`PAGE_SIZE`), а длинные подписи обрезаются.
- **Надёжный парсинг payload.** vkbottle отдаёт `message.payload` как JSON-строку — код корректно распаковывает и строку, и готовый словарь.
- **Логирование.** Все ключевые шаги и ошибки пишутся через стандартный `logging`.
- **Чистый код.** PEP 8, type hints, docstrings на каждую функцию, русскоязычные комментарии.
